# 🐢 金・原油タートル ジャーナル

GMOクリック証券（CFD）で、タートル手法（S2：55日ブレイク／20日ブレイク）の金・原油を手動で取引するための記録・ダッシュボード。けんた専用。

公開URL：https://kenta0920k-sketch.github.io/turtle-trading-journal/

## 主な機能
- 通貨は円。開始資産 80,000円（設定で変更できる）
- 損益は GMOクリックの決済結果（円）をそのまま入力する（換算はしない）
- エントリー時：日付、銘柄、Long/Short、ユニット番号（1〜4）、エントリー価格、SL、枚数、N、エントリー理由、どうなったら出るのか、画像
- 決済後：決済価格、損益（円）、損益率、保有時間、決済理由（2N損切り／20日ブレイク／その他）、ルール通りか（はい／いいえ）、いいえの理由、感情
- RRは「エントリー価格・SL・決済価格」から自動計算
- ダッシュボード：資産、今月損益、月間損益率、トレード数、勝率、平均RR、ルール通り率（今月と累計）、銘柄別損益（銘柄リストに連動）
- 月別履歴（ルール通り率つき）
- 設定：銘柄の追加・編集・削除（銘柄名、価格の単位、1枚の内容、最小枚数）。初期は金/JPY・WTI原油
- 新規記録：銘柄リストにない銘柄は「＋ 新しい銘柄を追加…」で入力できる（保存すると銘柄リストにも追加される）
- 設定：CSVで書き出し・読み込み（バックアップ用。トレード・銘柄・開始資産を1ファイルに入れる）

## データについて
- ブラウザの localStorage に保存する。別の端末・ブラウザとは同期されないので、定期的にCSVで書き出す
- 銘柄を削除しても、その銘柄のトレード記録は残る（「（削除済み）」と表示される）
- 画像は保存容量を抑えるため、幅1200pxのJPEGに縮小して保存する
- 旧版（ドル建て・暗号資産、2026-09 作成）の記録は消さずにブラウザに残してある。設定画面の「旧データをCSVで書き出す」で取り出せる
